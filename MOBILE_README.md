# CodeMentor — мобильное приложение (Expo)

Мобильная версия фронтенда CodeMentor на React Native (Expo).

## Запуск

```bash
npm start
```

Затем отсканируйте QR-код в Expo Go на телефоне или запустите эмулятор (Android/iOS).

## Подключение к backend API (реальный телефон)

Если приложение на **телефоне** пишет «Нет связи с сервером»:

1. **Узнайте IP компьютера**  
   На ПК откройте cmd (Windows) и введите `ipconfig`. Найдите **IPv4-адрес** (например `192.168.0.105`).

2. **Запустите backend так, чтобы он слушал все интерфейсы:**  
   В папке backend:  
   `python manage.py runserver 0.0.0.0:8000`  
   (не только `runserver` без 0.0.0.0 — иначе телефон не достучится.)

3. **Укажите этот IP в приложении** — один из способов:
   - **Через .env:** в папке `myApp` создайте файл `.env` с одной строкой:  
     `EXPO_PUBLIC_API_URL=http://192.168.0.105:8000/api`  
     (подставьте свой IP). Затем перезапустите: `npx expo start`.
   - **Через код:** в `lib/config.ts` замените `YOUR_PC_IP = '192.168.0.105'` на ваш IP.

4. **Телефон и ПК** должны быть в **одной Wi‑Fi сети**. Если ПК по кабелю — обычно та же сеть, что и Wi‑Fi роутера.

5. **Проверка:** на ПК в браузере откройте `http://ВАШ_IP:8000/api/` — должна открыться страница API (или JSON/ошибка 404, но не «сайт недоступен»).

6. В проекте backend в `config/settings.py` для разработки уже выставлено `ALLOWED_HOSTS = ['*']` при DEBUG, чтобы Django принимал запросы с вашего IP.

Эмулятор:
- **Android:** по умолчанию `10.0.2.2:8000` (в config при `USE_REAL_DEVICE = false`).
- **iOS:** `localhost:8000` (в config при `USE_REAL_DEVICE = false`).

## Структура экранов

- **Вход / Регистрация** — без авторизации редирект на логин.
- **Главная** — приветствие, блок курсов (по уровню), переход в каталог.
- **Курсы** — каталог с фильтрами по цене и уровню, поиск.
- **Курс [id]** — детальная страница курса.
- **Моё обучение** — заглушка (курсы в процессе).
- **Профиль** — аватар, имя, переход в Настройки и «Что нового», выход.
- **Настройки** — пункты настроек (заглушка).
- **Что нового** — список новостей из API `/news/`.

Все данные (логин, курсы, новости) запрашиваются с вашего backend API.
